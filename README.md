# 航空乘客体验分析与群体细分

## 项目简介

本项目通过两个独立案例研究航空乘客体验：案例一分析座椅舒适度与乘客推荐意愿之间的关系，并形成管理建议；案例二使用年龄和抵达延误进行乘客聚类，比较不同群组的满意率。

两个案例使用不同数据集，分别开展分析。评论数据中的推荐率与聚类数据中的满意率含义不同，不进行直接数值比较，也不将聚类结果视为对案例一结论的验证。

## 案例一：座椅舒适度与推荐意愿

使用课程提供的 `ETM1005_A2_AirlineReviews.csv`，按既定规则抽取 600 条评论，开展字段检查、分组统计和服务体验分析。

## 业务问题

航空公司希望判断座椅舒适度是否应成为客户体验改进的优先方向，以及座椅评分与乘客推荐意愿之间是否存在值得进一步调查的关系。

## 数据处理

- 按个人化规则筛选分析样本；
- 检查记录数量、唯一记录 ID、字段类型、缺失值和评分取值范围；
- 按舱位和座椅评分进行分组；
- 计算评分均值、中位数、推荐率和分组差异。

## 分析方法

使用 Pandas 对总体体验、座椅舒适度、舱位和推荐行为进行描述性分析，并进一步比较经济舱和商务舱中不同座椅评分群体的表现。通过 Results Fingerprint 保存关键样本与指标，支持结果复核和复现。

## 主要发现

- 座椅舒适度总体评价较为正面，但仍存在明显的低评分群体；
- 座椅评分较高的群体通常具有更高的推荐率，但评分为 3 分的群体出现了低于评分为 2 分群体的反常结果；
- 这一现象在经济舱和商务舱中仍然出现，且评分为 3 分的群体在性价比和总体体验上的表现更弱；
- 现有评论数据支持发现关联和识别调查方向，但不足以证明座椅本身造成了较低的推荐率。

## 从数据发现到产品决策

本项目不仅计算乘客评分和推荐率，还将统计结果转化为管理决策。分析显示，座椅舒适度总体评价较为正面，但低评分群体仍然明显存在；评分为 3 分的乘客推荐率反而低于评分为 2 分的乘客，且该现象在经济舱和商务舱中仍然存在。由于这一结果无法证明座椅本身造成了低推荐率，建议管理层先针对低评分乘客开展反馈调查，区分实际座椅问题与票价、服务预期不匹配，再决定维修、更换或调整服务说明等后续措施。

| 数据发现                             | 产品解释                           | 建议行动                 |
|---                                 |---                               |---                      |
| 座椅整体评价较为正面，但低评分群体仍然存在| 座椅不是全面失效，但存在明确的问题人群 | 优先调查低评分乘客的具体不满 |
| 评分 3 分组推荐率低于 2 分组           | 推荐意愿可能同时受到性价比和整体体验影响| 联合分析座椅、价格与服务 |
| 经济舱和商务舱均出现类似现象            | 问题可能不是单一舱位的偶发现象        | 开展分舱位的评论复核和访谈 |
| 数据主要来自评论观察                   | 能发现关联，但不能直接证明因果        | 暂不直接进行大规模座椅更换 |

## 技术栈

Python、Pandas、数据清洗与质量检查、描述性统计、分组分析、结果复现、管理报告。

## 项目边界与后续工作

本项目基于评论数据，未包含实际票价、航线、机型、座椅配置或维修记录，因此结论主要用于确定进一步调查方向。后续可以补充结构化问卷(用户调研）、航线和舱位信息，并建立分层模型或实验设计，以进一步判断不同因素对推荐意愿的相对影响。

## 案例二：乘客聚类与满意度比较

### 分析目标与数据

使用 [Airline Customer Satisfaction Dataset](https://www.kaggle.com/datasets/mehwishzehra/airline-customer-satisfaction-dataset)（`Invistico_Airline.csv`），探索年龄与抵达延误形成的乘客群体，并比较群组满意率。数据包含 129,880 条记录、22 个字段，抵达延误有 393 个缺失值。本案例由数据科学课程项目整理扩展而来。

### 分析方法

- 使用中位数填补抵达延误缺失值；
- 标准化年龄与抵达延误，避免数值尺度不同影响距离计算；
- 比较 k=2–6 的 inertia，通过肘部法选择 k=3；
- 计算各组人数、平均年龄、平均延误和满意率。满意度没有参与聚类，仅用于分析分组结果。

### 群组画像与主要发现

| 群组 | 乘客人数 | 平均年龄（岁） | 平均抵达延误（分钟） | 满意率 |
|---|---:|---:|---:|---:|
| 0：年龄较大的低延误群组 | 66,431 | 51.20 | 8.42 | 63.12% |
| 1：高延误群组 | 5,872 | 38.96 | 152.12 | 42.12% |
| 2：年龄较小的低延误群组 | 57,577 | 25.89 | 8.72 | 46.35% |

高延误群组的满意率最低。两个低延误群组的平均延误接近，但满意率相差 16.77 个百分点，提示需要进一步研究舱位、旅行目的和服务评分等因素，而不能只关注延误。

### 分析边界与后续方向

这些差异是描述性关联，不能证明年龄或延误导致满意度变化。聚类只使用两个特征，结果受到标准化方式、极端延误值和 k 值选择的影响；目前尚未验证聚类稳定性，也未证明其优于简单的年龄与延误规则分组。后续可比较群组的舱位和旅行目的构成，检查不同随机种子与样本下的分组稳定性，并评估轮廓系数。

本案例提供进一步调查乘客体验的线索，不直接支持按群组制定服务政策。
